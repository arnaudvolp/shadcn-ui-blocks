# Shadcnship

ShadcnShip is a collection of production-ready blocks built for founders and teams who want to ship modern landing pages and SaaS applications faster. It provides a large, growing library of responsive, fully-typed blocks built with shadcn/ui, Tailwind CSS, Next.js, and TypeScript. The components are fully open and editable, so they fit naturally into your codebase without introducing a new design system or locking you into fixed styling patterns.

**Star this repo** to follow development — [shadcnship.com](https://shadcnship.com)

**Tech stack:** Next.js 16 · TypeScript · Tailwind CSS · shadcn/ui · Supabase / PostgreSQL

## Overview

Every block copies straight into your project with a single command. There is no package to depend on and no design system to adopt — the code becomes yours, themed by your own shadcn tokens, ready to edit freely.

- **You own the code.** Blocks live in your repo and read like code you wrote.
- **Themes with your app.** Built entirely on shadcn tokens — your radius, colors, and dark mode, with no style overrides.
- **Fully typed.** Clean TypeScript props with sensible defaults on every block.
- **Responsive and accessible.** Mobile-first layouts following WAI-ARIA patterns.
- **SaaS-ready.** Data-driven blocks wired for Supabase and PostgreSQL.

## Start Using

Visit [shadcnship.com](https://shadcnship.com) to browse and copy any block, or install one directly:

```bash
npx shadcn@latest add "https://shadcnship.com/r/hero-01.json"
```
